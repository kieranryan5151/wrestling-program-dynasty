# Wrestling Program Dynasty

Wrestling Program Dynasty is a college wrestling and freestyle wrestling management simulation game.

## Current Development

The game is currently under active development.

The current build is contained in:

`index.html`

## Branches

- `main` — Stable, approved version of the game.
- `development` — Active development, new features, fixes, and testing.

New builds should be tested on `development` before being merged into `main`.

## Running the Game

The current development build can be run by opening `index.html` in a web browser.

## Development Workflow

1. Develop and test new versions on `development`.
2. Commit working changes to GitHub.
3. Test the updated game.
4. Merge approved versions into `main`.
5. Use stable versions for releases/distribution.

## Status

Private development project. Not currently released to the public.
